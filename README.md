## Project Description
This project is a Java-based Employee Management System implemented according to the provided UML class diagram. It demonstrates Object-Oriented Programming (OOP) principles such as inheritance, polymorphism, encapsulation, and abstract classes. The system manages different types of employees (Monthly, Hourly, and Commission-based) grouped under specific departments.

## Project Structure
- `src/model/`
  - `Gender.java` (Enum)
  - `Employee.java` (Abstract Base Class)
  - `MonthlyEmployee.java`
  - `HourlyEmployee.java`
  - `CommissionEmployee.java`
  - `Department.java`
- `src/test/`
  - `MainTest.java` (Main execution class with demo data)

## How to Run
1. Open the project in your preferred Java IDE (IntelliJ IDEA, Eclipse, NetBeans, or VS Code).
2. Navigate to `src/test/MainTest.java`.
3. Run the `main` method to see the console output demonstrating employee creation, department assignment, and salary calculations.
